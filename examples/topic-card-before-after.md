# Example: Topic Card Before and After

## Input (Before)

```text
I keep writing support response tips, but it feels crowded and unclear.
Can you help me choose one thing to build as a skill first?
```

## Output (After)

```markdown
## One-Liner

Build a small `skill-market-map` topic card to compare crowded vs. under-served skill themes and pick one low-risk starter candidate.

## Target User

Support-led teams that need one stable workflow as a public skill.

## Pain Point

The team has many templates but no decision rule for which template to convert first.
```

Use this output pattern as the minimum shape for a new topic card.
